# Rubics-cube-solver-
Object-Oriented Core: Accurate 3x3 face tracking and move history.  Full Control: F,R,U,B,L,D and prime moves with real-time feedback.  Smart Solver: Layer-by-layer method (White Cross → Middle Layer → Yellow Face) that solves any cube.  Learning Tool: Step-by-step solution display and full 6-face visualization.
